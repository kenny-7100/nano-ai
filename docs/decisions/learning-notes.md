# 使用项目内学习笔记技能

日期：2026-11-26

## 问题

项目需要在问答、讨论和实践中持续识别可复用知识，便于复习；规则应随仓库维护，针对学习 LLM 和积累工程能力设计。

## 选择

在 `.agents/skills/learning-notes/SKILL.md` 维护独立技能，并在根目录 `AGENTS.md` 指定相关任务读取它。无需安装或修改全局技能，也不依赖当前会话的技能列表是否刷新。

## 对原方案的审视

全局 `markdown-kb` 的去重、索引、互链和证据意识值得保留。但强制平铺、时间版本文件名、每次语义更新复制文件及维护独立日志，会增加本项目复习与维护的负担。

因此改为主题目录、稳定文件名、原地更新与 Git 历史，强调具体解释、误区和自测。原始五个知识库文件保存在 `knowledge/archive/`，当前阅读入口只链接整理后的笔记。不把原技能的来源当作这一选择的依据，也不判断它是否适合其他项目。

## 边界与验证

技能负责知识整理，Git 推送约定继续以 `AGENTS.md` 为准。不会因为整理笔记扩大任务授权，也不强制每轮产生新文件。

创建时检查技能格式与文档链接，并用现有三篇笔记演示组织方式。此处没有声称技能已在新会话中自动发现或经过长期使用验证；后续根据实际复习体验调整。
