# 单卡训练：预训练、微调与目标边界

## 原始问题与摘要

一张 32GB 显卡能训练什么样的 LLM？

需要先区分从随机初始化开始的预训练，与在已有模型上进行的微调。两者训练成本、学习价值和产出能力不同。以下规模是项目起点建议，不是硬件上限、实测结果或质量保证。

## 三种训练路线

| 路线 | 更新什么 | 在本项目中的用途 |
| --- | --- | --- |
| 从零预训练 | 随机初始化模型的参数 | 理解数据、结构、优化与生成如何组成完整训练过程 |
| 全参数微调 | 已有模型的全部参数 | 适配任务，但要容纳全部训练状态 |
| LoRA / QLoRA | 主要训练插入的适配参数 | 在较小显存预算下适配已有模型 |

LoRA 使用低秩适配，QLoRA 通常结合量化的基础权重与适配器训练。它们仍需要运行基础模型的前向和反向相关计算，也仍有激活与其他开销，不代表只为适配器分配显存。

## 本项目的暂定目标

- 先调试很小的模型，再评估约 100M～150M 参数的简单故事模型。
- 后续微调可以从适合任务的 3B～8B 模型开始评估，采用参数高效训练；具体能否放下取决于上下文、批次、实现与精度。
- 100M 表示一亿参数，1B 表示十亿参数。
- 简单故事续写不等于可靠知识问答、复杂推理或通用对话能力。

## 显存为什么不只包含权重

训练通常还需要梯度、优化器状态、前向激活和临时缓冲区。自回归推理通常不保留训练用梯度与优化器状态，但可能使用随上下文和并发增长的 KV cache。

因此，“权重文件能放进 32GB”不能推出“可以在 32GB 上完成全参数训练”。

## 如何判断实验可行

先进行小规模正确性检查，再用目标 GPU 短跑，记录实际配置、峰值显存、tokens/s、验证指标和费用。累计训练 tokens 可以包含重复见过的数据；它不等于不重复语料量，增加重复次数也不保证能力继续提升。
