# nano-ai

通过亲手实现、训练、评估和部署语言模型，建立进入 AI 行业所需的模型理解、实验能力与工程能力。

这是一个以学习为主的工程项目。代码能运行只是起点；我们还需要解释设计、验证假设、分析失败，并留下可复现的证据。

## 项目目标

1. 从最小语言模型开始，逐步理解 Transformer 与自回归训练。
2. 在单张 32GB GPU 上，从零训练约 100M～150M 参数的小模型，并完成对照实验。
3. 使用已有模型学习参数高效微调，围绕一个可评估的实际任务验证收益。
4. 部署推理服务，测量质量、延迟、吞吐和显存，形成可展示的完整作品。

第二阶段之前再根据数据、预算和兴趣确定训练语言及语料。微调任务暂以“根据组件类型和需求生成 TSX”为候选，不视为已经确定的产品方向。参数规模是实验起点，不是能力保证。

## 设计原则

- 先理解最小实现，再使用成熟工具提高效率。
- 维持一套逐步演进的主线代码，避免复制多个阶段的完整训练工程。
- 每次只引入必要的概念与抽象，保留可以读懂的数据流。
- 用固定评估和控制变量实验判断改进，不能只看生成样例。
- 本地先验证正确性，租用 GPU 后再验证性能与扩大规模。
- 以实际结果记录能力与局限，不把采用某个技术名词当作成果。
